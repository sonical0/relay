## Claude Code — capabilities

- Full filesystem access (no sandbox) → **orchestrator role**
- Subagents: Explore, Plan, general-purpose
- Skills: discovered in `.claude/skills/` only; rules in `.claude/rules/` (both generated by `TOOLS/skills-link.mjs`)
- Structured questions: `AskUserQuestion`
- Node scripts, file writing, web

## Hooks

Installed in `~/.claude/settings.json` (or `$CLAUDE_CONFIG_DIR`) by `npm run init` or
`node relay-setup-hook.js`. Local to the machine, never committed.

| Event | Script | Role |
|---|---|---|
| `SessionStart` `startup\|resume\|clear\|compact` | `relay-start-hook.js` | injects the targeted state and the resume card; re-injects them after compaction; refreshes the state in the background |
| `SessionStart` (async) | `relay-setup-hook.js` | repairs missing or stale hooks, re-links skills and rules |
| `Stop` | `relay-stop-hook.js` | asks once for today's journal entry; launches the detached after-turn work |
| `PreToolUse` `Bash` | `TOOLS/supervision/supervision-guard.js` | push guard during supervision; exits at once otherwise |

## Browser panel (optional)

If a terminal multiplexer with a visible browser panel (e.g. wmux) is installed, prefer it
over headless browsing so the user sees what you do. Probe it once per session. With several
agents in one wmux workspace, each drives **its own** tab: create it with
`node TOOLS/supervision/wmux-tab.mjs --title "…" --show`, pass `--surface <id>` to every
command, navigate with `eval "location.href='…'"`, close it at the end (DECISIONS, 2026-10-15).
